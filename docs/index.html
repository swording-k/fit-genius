Why FitGenius

AI 懂你的起点

根据性别、经验水平、目标多选生成专属计划。新手自动退阶到自重变式——不会让你做不了的标准俯卧撑。

🍎

苹果原生质感

纯 SwiftUI 构建，遵循 Apple Human Interface Guidelines。每一个圆角、每一处动效都像系统自带一样自然。

🔒

隐私优先设计

数据主要存储在本地设备。登录可选 Apple 登录，云同步走腾讯 CloudBase 加密通道。你的身体数据属于你自己。

智能计划生成
告别千篇一律

告诉 AI 你的目标——增肌、减脂、塑形、力量提升、甚至减压与睡眠。 它会结合你的训练环境和可用器械，生成完整的循环训练计划。

  • ✓ 支持 3/4/5/7 天任意循环周期
  • ✓ 每个动作含组数、次数、重量建议和备注
  • ✓ 一键标记完成，实时追踪进度
  • ✓ 对话一句就能改计划："膝盖疼，换掉深蹲"

AI 助手对话
随时调整方向

不只是聊天机器人——它是你的健身顾问。 上传身材照片获取体型分析，询问动作要领， 或者直接告诉它你想改什么。

  • ✓ 自然语言理解你的修改意图
  • ✓ 支持上传照片进行身材分析与动作识别
  • ✓ 基于 Apple Vision 的本地姿态检测（深蹲/硬拉/卧推）
  • ✓ 原始视频不上云端，评分全在本地完成

饮食营养分析
吃对才能练好

文字记录或拍照上传，AI 自动拆分每餐的 热量、蛋白质、碳水、脂肪。 每日趋势一目了然，饮食建议贴合你的训练目标。

  • ✓ 文字 / 拍照双模式记录饮食
  • ✓ AI 自动识别食物并计算营养成分
  • ✓ 每餐独立显示热量与三大营养素
  • ✓ 营养趋势图表可视化追踪

数据驱动进步
看见自己的成长

训练天数、完成动作数、总组数、训练容量—— 每个维度都有统计。重量增长曲线让你看到 每一次突破的真实轨迹。

  • ✓ 坚持天数自动追踪（连续未完成则清零）
  • ✓ 训练容量趋势折线图
  • ✓ 每个力量的重量增长曲线
  • ✓ iOS Widget 主屏幕小组件一览无余

Privacy First

你的数据，只属于你

我们不卖数据，不做追踪，不强制登录。
隐私不是功能，是底线。

📱

本地优先存储

所有数据默认存于本地 SwiftData 数据库，无需联网即可使用全部核心功能。

🍎

Apple 登录可选

登录完全可选，仅用于跨设备同步。支持 Sign in with Apple，不留第三方账号。

☁️

加密云同步

选择同步后，数据通过 CloudBase HTTPS 加密传输，JWT session 保护身份安全。

🔐

零 API Key 泄露

iOS 包内不含任何第三方密钥。AI 请求经后端代理转发，Key 只存在于服务端环境变量。
